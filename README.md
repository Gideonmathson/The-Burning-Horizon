
# The Burning Horizon

**heat.perception.body.world**

A multi-author Jekyll blog for GitHub Pages.

## Publish free on GitHub Pages
1. Create a new public GitHub repository, for example `the-burning-horizon`.
2. Upload everything in this folder to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then Save.

## Add a post
Create a Markdown file in `_posts` named `YYYY-MM-DD-short-title.md` and use the front matter from any sample post.

## Add an author
Add them to `_data/authors.yml`, then use their author key in post front matter. Duplicate an author page if you want a dedicated profile.
